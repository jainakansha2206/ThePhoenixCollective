# ThePhoenixCollective
A store where you can collect Unutilzed Things for fashion 

Microservices based backend system using Spring Boot,
Spring Cloud Gateway and PostgreSQL.

## Services
- User Service - JWT ,Zipkin ,As Erureka Client ,Spring actuator , Security , Email , Lombok , Validation , Mapstruct
- Product Service - JWT , Zipkin ,As Eureka Client , Spring actuator
- Order Service
- Payment Service
- API Gateway - JWT ,Zipkin ,As Gateway ,  Erureka Client ,Spring actuator , Security , Webflux , circuitbreaker resilience4j
